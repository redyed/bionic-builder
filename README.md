# Bionic Builder

Static site for [thebionicbuilder.com](https://thebionicbuilder.com) — built with Astro and Tailwind.

## Stack

- Astro (static output)
- Tailwind CSS v4
- Fontsource: Archivo + IBM Plex Mono

## Pages

- `/` — homepage
- `/setups` — setups index and articles
- `/now` — weekly value ledger

## Development

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub → Vercel.
